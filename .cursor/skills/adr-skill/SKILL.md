# adr-skill (Cursor adapter)

This skill produces enterprise-grade Architecture Decision Records (ADRs) for the current repository. It runs in **auto-mode** by default: the Orchestrator advances through interview, drafting, review, and promotion without asking the user to confirm each phase. `--no-auto` opts back into manual gating. Equivalent skill bodies ship for Claude Code 2.0+ at `assets/claude-code/skills/adr-skill/SKILL.md`, for Codex CLI 0.34+ at `assets/codex/skills/adr-skill/SKILL.md`, and as an `AGENTS.md` fragment for any other agents.md-aware host at `assets/agents-md/AGENTS.fragment.md`. All four adapters reference the canonical Orchestrator and Reviewer prompts at `prompts/*.md`, so review behaviour is identical across hosts.

## Activation

Use the explicit invocation `/adr-skill` in chat. The skill does not auto-activate.

## What you (the agent) must do

1. Load the host-runtime Orchestrator prompt at `prompts/orchestrator.md` from the installed `adr-skill` package. The Orchestrator owns the workflow end to end. Do not improvise outside that prompt.
2. Use only the allowlisted CLI subcommands. The `beforeShellExecution` hook rejects anything else with `permission: "deny"`:
   - `npx adr-skill new --title "<title>" [--template madr|lite] [--no-auto]`
   - `npx adr-skill index`
   - `npx adr-skill resume [--run-id <id>]`
   - `npx adr-skill verify`
   - `npx adr-skill cartograph [--max-files N]`
   - `npx adr-skill read [--max-lines N]`
   - `npx adr-skill research [--no-network] [--live] [--citation-budget N] [--corpus <path>]`
   - `npx adr-skill synthesize`
   - `npx adr-skill brownfield [--mode auto|brownfield] [--no-network] [--live] [--citation-budget N] [--no-auto]`
   - `npx adr-skill rca search [--text "..."] [--component <id>] [--error-code <code>] [--tag <tag>] [--limit N]`
   - `npx adr-skill rca explain --adr <path-or-id> [--for "incident text..."]`
   - `npx adr-skill rca list [--component <id>] [--status accepted|deprecated|all]`
3. Route every draft through the Reviewer subagent at `.cursor/agents/reviewer.md`. The Reviewer emits `review.md`; in auto-mode the Orchestrator auto-promotes on `PASS` or `WARN` and halts on `BLOCKER`. In `--no-auto` mode the same `review.md` is used for human gating.
4. If the conversation hits a compaction boundary, the `preCompact` hook writes `.adr-skill/state/runs/<run-id>/briefing.md`. On the next turn after compaction, read that file first.
5. Output is plain Markdown only. No emojis, no pictographic Unicode anywhere. Verbatim banned ranges live in the Reviewer prompt (`STYLE-001`).

## Outputs the skill produces

- `docs/adr/NNNN-<slug>.md` — one ADR per decision.
- `docs/adr/README.md` and `docs/adr/index.json` — regenerated by `npx adr-skill index`; byte-identical on rerun. Phase 5 surfaces `rca-keywords`, `error-codes`, `components`, and `severity-hint` per ADR.
- `.adr-skill/state/runs/<run-id>/` — per-run interview answers, drafts, review reports, briefings.
- `.adr-skill/state/rca-reports/<NNNN>-<slug>.json` — output of `rca explain`; validated against `schemas/rca-report.schema.json`.
- `.adr-skill/cache/<sha256(url)>.json` — opt-in live Researcher cache. Created only when `--live` is set; safe to delete.
- `.adr-skill/logs/<YYYY-MM-DD>.log` — append-only NDJSON.

## RCA query surface (Phase 5)

During an incident or postmortem, query the published ADR set without spawning the full agent:

- `npx adr-skill rca search --error-code <code>` ranks ADRs by RCA-relevant fields. Determine ranking via BM25-lite over `rca_keywords + error_codes + components + tags + title`.
- `npx adr-skill rca explain --adr <id-or-path> [--for "incident text"]` extracts Decision, Consequences, and Considered Options into a structured `rca-report.json` plus a Markdown summary.
- `npx adr-skill rca list [--component <id>] [--status accepted|all]` lists candidate ADRs.

The recipe at `recipes/incident-triage.md` walks an incident-triage agent through the typical sequence.

## Outputs the skill does not produce

- `git` commits or pushes.
- Pull-request bodies, issue summaries, or any chat output beyond the workflow summary at the end of the run.
- Live web fetches when `--no-network` is set; the Researcher emits `skipped:no_network` records and the Synthesizer falls back to in-tree evidence.
